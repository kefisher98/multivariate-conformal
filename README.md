# Multivariate Conformal
Code for multivariate conformal predictions for atomistic models. This repository implements the numerical experiments described in


Fisher, Katharine, Herbst, Michael, Kermode, James, and Marzouk, Youssef. (2026) Multivariate conformal uncertainty propagation in multitask atomistic simulation: Successes and pitfalls. Under review.


 
# Experiments


### Getting Started

All experiments are implemented in Julia, but key steps to read and represent atomistic configurations are implemented with the Python packages ase and QUIP, accessed through the Julia package, PyCall. Python dependencies are captured in the requirements.txt file and installed via

```
pip install -r requirements.txt
```

Julia dependencies are recorded in the Project.toml and Manifest.toml. You can open the Julia REPL for this project by entering this directory and calling

```
julia --project=.
```
In the case that PyCall is accessing the wrong version of Python, the Julia environmental Python can be reset by implementing the REPL and calling

```julia
using Pkg
ENV["PYTHON] = joinpath(Conda.PYTHONDIR, "python")
Pkg.build("PyCall")

using Conda
Conda.pip_interop(true)
Conda.pip("install", ["numpy","matscipy","ase","julia"])
Conda.pip("install", "git+https://github.com/casv2/pyjulip")

# rebuild Pycall
Pkg.add(PackageSpec(name="PyCall", rev="master"))
ENV["PYTHON"] = joinpath(Conda.PYTHONDIR, "python")
Pkg.build("PyCall")
```

### Recreating plots

To recreate the figures in the paper, run

```
bash make_plots.sh
```


### Synthetic experiments

To run all experiments based on synthetic data and create the figures shown in Fisher et al. (2026), call  

```
bash run_synthetic.sh
```

Within the bash script, it is possible to adjust the correlation of inputs within the synthetic calibration and testing sets. Further modifications are possible if the user changes the parameters set at the bottom of /src/run_synthetic.sh. The fgures are defined within /src/make_synthetic_plots.jl.


### High dimensional targets and conformal risk control

To test multivariate conformal and risk control algorithms on high dimensional targets, we construct calibrated uncertainty sets for the energies and atomic forces of silicon configurations. These tests can be run and visualized by calling

```
bash run_energy_force_calibration.sh
```

Modifications can be made to the test at the bottom of /src/energy_force.jl, and modifications to the figures can be made in /src/make_energy_force_plots.jl.

Predictions rely on a subset of regressors approximation to the covariance of energies and forces in the training data set. Compressed precomputed copies of these structures are stored in /data/covariance. Details on recreating these structures can be found lower in this README file.


### Elastic constant computation

The paper presents two categories of elastic constant prediction experiments. In the first, the uncertainty of the predicted energy of perturbed atomic configurations is conformally calibrated, then uncertainty is propagated to the elastic constant. These tests can be run and visualized by calling

```
bash run_energy_elastic_constant.sh
```

Modifications to the experimental settings can be made at the bottom of /src/energy_elastic_constant.jl.

In the second category of tests, the uncertainty of the predicted stress of perturbed atomic configurations is conformally calibrated, then uncertainty is propagated to the elastic constant. These tests can be run and visualized by calling

```
bash run_stress_elastic_constant.sh
```

These tests use a precomputed covariance matrix for the dataset stresses. Details on how to precompute this matrix are given below. Modifications to the experimental settings can be made at the bottom of /src/stress_elastic_constant.jl. Figures can be altered by editing /src/make_elastic_constant_plots.jl.


### Vacancy formation computation

The final set of experiments presented in the paper use a multitask surrogate to predict energy for bulk as well as vacancy configurations. The uncertainty on these predictions is conformalized, and this uncertainty is propagated to vacancy formation energy. Tests and visualizations can be regenerated by calling

```
bash run_vacancy_formation.sh
```

Modifications to the experimental settings can be made at the bottom of /src/vacancy_formation.jl, and figures can be altered by editing /src/make_vacancy_formation_plots.jl.

## NOTE ON RUNTIME: 

Coverage is evaluated through many replications of each test for a different training, calibration, and testing sets. Each test involves traiing a surrogate model and using that model to perform multiple geometric relaxations. Consequently, the tests can take several hours to complete. To improve runtime, the julia scripts for the elastic constant and vacnacy formation experiments support running tests in parallel. Edit the top of the relevant bash script to include appropriate settings for your hpc resource and assign the variables **$task_id** and **$task_count**. 

Note that the runtime of these experiments is not reflective of the runtime of conformal algorithms deployed in realistic workflows. The computational cost is incurred through random replications of atomistic simulations. 

# Data


### Configurations

Our atomistic experiments use configurations from the silicon Gaussian approximation potential (GAP) dataset:

A. P. Bart&oacute;k, J. Kermode, N. Bernstein, and G. Cs&aacute;nyi, “Machine Learning a General-Purpose Interatomic Potential for Silicon,” Physical Review X 8, 41048 (2018), arXiv:1805.01568.



### Precomputed data

Our experiments use precomputed stress and force covariance matrices, stored in /data/covariance/. To regenerate these structures call

```
bash precompute_covariance.sh
```

To alter the settings or hyperparameters for these structures, see /src/precompute_covariance_blockwise.jl, /src/precompute_energy_stress_covariance.jl, and /src/precompute_sor_approximation.jl.

A small amount of data is set aside to tune model hyperparameters, described in the supplemental material of the paper. The script /src/tune_energy.jl tunes the ratio of the kernel variance and training data noise. The scripte /src/tune_finite_diff_stress.jl tunes the step size of the finite difference approximation applied in the elastic constant predictions. Finally, /src/tune_multitask.jl tunes the variance and correlation for multitask surrogates. All can be called via 

```
bash tune_hyperparameters.sh
```

and results are stored in /data/hyperparameters.
